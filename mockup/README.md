# Макет публічного сайту Euromaxi UA

Статичний HTML/CSS/JS макет v1 для погодження з клієнтом.
Візуальний тон: [energy.stls.store/uk](https://energy.stls.store/uk/) — **білий фон, сині написи UI** (`#0073B8`), **чорні назви товарів**.

## Як відкрити

```bash
cd mockup
python3 -m http.server 8765
```

Далі: http://127.0.0.1:8765/

## Структура як у Stylus

- Верхні лінки + шапка: лого · **Каталог товарів** · пошук · кошик
- Головна: плитки брендів · промо-банер · смуга брендів · хіти/новинки
- Картки товарів у стилі вітрини, кнопка «Купити»; на мобільному — **2 в рядку**
- PDP: пріоритетні характеристики (ємність, ном. потужність, батарея, розʼєми, зарядка, функції)
- Checkout: лише Monobank, email обовʼязковий

## Асортимент-заглушки

Jackery · Bluetti · Anker — побутові portable power stations (не EV).
